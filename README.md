# Backend Web Application

A PHP-based backend web application focused on secure user management, authentication, and database-driven functionality.

## Tech Stack
- PHP
- MySQL / PostgreSQL
- SQL
- Git

## Features
- User authentication and login validation
- CRUD operations for managing application data
- Secure handling of user information and access control
- Database integration and backend system architecture
- Structured controller-based application design

## Project Structure
- `index.php` — application entry point
- `config/` — database and application configuration
- `controllers/` — business logic and request handling
  - `AuthController`
  - `ItemController`
  - `PurchaseController`
  - `RatingController`
- `security/` — authentication and security logic

- Database connectivity and CRUD implementation
